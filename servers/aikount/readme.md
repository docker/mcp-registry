# Aikount MCP Server

Spanish accounting from any MCP-compatible agent: sales invoices and quotes,
supplier invoices read by AI, bank reconciliation, the PGC ledger and the AEAT
tax models.

- Documentation: https://aikount.com/en/docs/agente-api/conectar-claude
- Source (local stdio variant): https://github.com/mutonby/aikount-mcp (MIT)
- Get an API key: https://aikount.com → Settings → Connect agent (free plan available)

The hosted endpoint also supports OAuth 2.1 with Dynamic Client Registration if
you prefer not to configure a static API key.
