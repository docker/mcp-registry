# VPSnet

[Remote connection and permissions](https://github.com/bacarrdy/vpsnet-mcp/blob/main/docs/REMOTE_MCP.md)

Connect to `https://mcp.vpsnet.com/mcp` using customer OAuth. Select the
services and permissions needed for the task. Tools are discovered dynamically
for the connected authorization. No VPSnet account API key is required.
