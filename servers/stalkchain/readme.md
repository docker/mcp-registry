See the [StalkChain MCP documentation](https://stalkchain.com/mcp) for OAuth sign-in, supported clients, and usage.

The Docker catalog connects to the hosted directory endpoint at `https://data.stalkchain.com/mcp/directory`. Sign in with a StalkChain account. Research queries use account credits. This endpoint excludes trading, transaction signing, and fund transfers. The connector can manage the signed-in account’s alerts.
