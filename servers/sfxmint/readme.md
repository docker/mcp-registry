Docs: https://sfxmint.com/api/docs#mcp

This unauthenticated configuration supports library search, sound details and downloads. Optional custom generation requires a SFXMint account and credits; it is not enabled by this no-key configuration. Sounds are AI-generated or procedurally synthesized and offered under CC0 1.0. The public integration repository is https://github.com/flreey/sfxmint-mcp; it is documentation and client integration material, not the hosted server implementation.
