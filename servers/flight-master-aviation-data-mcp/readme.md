# Flight Master Aviation Data MCP

Official aviation data MCP service provided by Flight Master DAST (航班管家 DAST).

## Capabilities

- Real-time and historical flight status
- Flights between airports by route and date
- Onboard experience data
- Flight delay and cancellation risk prediction
- Airport weather forecasts
- Real-time and historical flight trajectory data

## Remote MCP Endpoint

https://fly.huoli.com/mcp/dast_mcp

## Transport

Streamable HTTP

## Authentication

Bearer API Key is required.

Users can obtain an API Key from the Flight Master DAST platform.
