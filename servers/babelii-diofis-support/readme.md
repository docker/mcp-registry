# Babelii-Diofis Customer Support

Babelii help for AI agents: official FAQ, order status, product advice and support tickets to staff. It cannot place, cancel or refund orders.

Endpoint: https://babelii.diofis.net/mcp/support/ (Streamable HTTP, no sign-in required).

Operator: Diofis Enterprise / PT Data Infra Ekselen. The same server is published in the official MCP Registry as `net.diofis/babelii-support`.

## More Information

See the [Babelii-Diofis guide for AI agents](https://babelii.diofis.net/en/ai), the [privacy policy](https://babelii.diofis.net/en/privacy-policy) and the [terms of service](https://babelii.diofis.net/en/terms-of-service).
