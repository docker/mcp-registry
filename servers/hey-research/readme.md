# HEY Research Lab MCP Server

HEY Research Lab keeps the public record of building on Robinhood Chain (chain id 4663): which projects are still shipping, what they shipped and when, their contracts and what changed, each fact with a link to its source.

The hosted server is read-only and needs no key or account. Every answer comes from HEY's own records, with evidence ids, and says plainly where HEY has no evidence. It gives no investment advice, price predictions or buy/sell signals.

## Example questions

- Who built this Robinhood Chain token, and is the team still shipping?
- What did this project ship in the last 30 days?
- What changed on Robinhood Chain this week?
- Does the project's own site name this contract?
