DocStar turns your product's API into published docs that your users' AI assistants can read and call.
Your AI assistant can document each endpoint from your code, publish the docs, and give you one link to share. Your users' assistants then look up any endpoint and call your API with the exact URLs, fields and auth from your docs, so they don't guess.
Reading docs needs no account; changes need DocStar sign-in.

For documentation, visit https://github.com/swayammaheshwari/docstar-mcp#readme
