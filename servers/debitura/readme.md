Debitura is a B2B cross-border debt collection platform matching unpaid invoices to licensed local partners in 180 countries on a No Cure, No Pay basis.

The remote MCP server uses streamable HTTP. Configure your own Debitura API key in the `DEBITURA_API_KEY` secret; it is sent as the `XApiKey` header. No API key is included in this contribution.
