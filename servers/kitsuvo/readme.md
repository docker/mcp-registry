Docs: https://github.com/leancoderkavy/kitsuvo-integrations/blob/main/docs/quickstart/cloud-relay.md

Install Kitsuvo and start the local connector before OAuth authorization. Kitsuvo publishes MCP protected-resource and authorization-server metadata and supports dynamic client registration, so no personal access token is required. Each client receives access only to the explicitly consenting isolated browser. The relay has ephemeral state; reconnect and reauthorize after relay restart.
