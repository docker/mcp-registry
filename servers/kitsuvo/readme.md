Install Kitsuvo and start the local connector before OAuth authorization. Kitsuvo publishes MCP protected-resource and authorization-server metadata and supports dynamic client registration, so no personal access token is required. Each client receives access only to the explicitly consenting isolated browser. Temporary terminal connectors require reauthorization after disconnect; the optional installed background connector resumes approved grants across restarts.
