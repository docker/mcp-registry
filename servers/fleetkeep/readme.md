# Fleetkeep

Review fleet actions, search vehicles and inspect maintenance dates and reminder delivery history.

Published by Studea.

Docs: https://fleetkeep.co.uk/developers

## Access

OAuth requires a supported registered client. Read-only endpoint; full connector excluded.

Connect to `https://fleetkeep.co.uk/mcp` using OAuth and approve only the access you need. No credentials belong in this catalogue entry.
