# Cassette Publish

Publish and manage browser games through the hosted Streamable HTTP MCP endpoint at https://cassette.gg/mcp/publish.

Sign in through OAuth and approve the client on Cassette when prompted. A person approves access; this server does not set prices or move money.

Documentation and connection instructions: https://cassette.gg/agents/guide.md

This is a vendor-hosted service; the server implementation is not public source.
