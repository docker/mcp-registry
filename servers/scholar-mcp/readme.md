# Scholar MCP

Search papers, follow citations and related work, read primary text and figures,
and save selected papers and notes in a local library.

The published image runs the MCP server over stdio with its bundled CPU reader.
This catalog entry enables the eight-tool research profile. Source keys are
optional; the default ranking runs locally.

The `scholar-mcp-data` named volume keeps the local library, PDFs and notes
across gateway restarts. The image runs as its unprivileged `scholar` user.

Quickstart and advanced configuration: https://liyux3.github.io/scholar-mcp/

Package: https://pypi.org/project/scholar-mcp/0.9.0/
Repository: https://github.com/Liyux3/scholar-mcp
