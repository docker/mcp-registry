# BestPrice Shopping

BestPrice Shopping is the public, read-only MCP surface for BestPrice.gr.

- Endpoint: https://mcp.bestprice.gr/mcp
- Authentication: none
- Transport: Streamable HTTP
- Market: Greece
- Capabilities: shopping decisions, product search, current merchant-offer comparison,
  delivered totals, and price history
- Documentation: https://www.bestprice.gr/mcp
- Source and client manifests: https://github.com/TheBestCo/bestprice-mcp

The four shopping tools do not place orders, take payment, create alerts, or expose direct merchant links.
