# Valyu

Documentation: https://docs.valyu.ai/integrations/mcp-server

Connect to `https://mcp.valyu.ai/mcp` using Streamable HTTP and sign in with your Valyu account through OAuth.

The server provides six tools for web and specialist-source search, dataset discovery, URL extraction, and creating, checking, and managing DeepResearch tasks. Source coverage and access depend on the account. Usage is billed to the authenticated Valyu organization.

Create an account at https://platform.valyu.ai. See https://docs.valyu.ai/pricing for current pricing.
