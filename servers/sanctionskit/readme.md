# SanctionsKit

[Documentation and setup](https://www.sanctionskit.com/resources/mcp)

Use the public `search_docs`, `get_doc`, `get_api_schema`, and
`validate_screening_request` tools without an API key. Request validation checks
structure only; it does not screen a subject, query an account, or establish that
coverage or a policy is available.

This entry does not configure OAuth, API keys, or authenticated account access.
The shared endpoint also advertises account tools; discovery does not mean those
tools can be used anonymously. Use the public developer tools with this entry.
Free synthetic sandbox screening and paid production screening are separate
account workflows, not capabilities verified by this catalog contribution.
