FineRx MCP server (hosted, no key needed): observed US prescription prices per pharmacy with observation dates, the free FineRx discount card, nearby pharmacies, prescription options, US equivalents of foreign-brand medicines, pages in 12 languages. Prices are observed estimates, never guarantees; the card is not insurance; no medical advice. Source package: https://pypi.org/project/finerx-mcp/ (MIT). Public API docs: https://www.finerxfinder.com/api/public/v1/docs
