# Magic Hour

Generate and edit videos, images, and audio through Magic Hour's hosted MCP server. The server exposes Magic Hour's AI media APIs as tools for MCP-compatible clients.

## Setup

1. Create an API key in the [Magic Hour Developer Hub](https://magichour.ai/developer).
2. Configure `MAGIC_HOUR_API_KEY` with that key.
3. Connect to `https://mcp.magichour.ai/` using the streamable HTTP transport.

See the [Magic Hour MCP documentation](https://magichour.ai/mcp) for supported tools and examples.
