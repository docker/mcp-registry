# Revamp

Create or redesign websites and build web apps by chatting. Start from an existing website URL or describe what you want, then preview and refine the result in the same conversation.

Docs: https://revamp.dev/

## Connect

Revamp is a hosted server at `https://app.revamp.dev/mcp` using Streamable HTTP. No local server, image, or API key is required. Connect your Revamp account through the sign-in and consent flow. Each connection can access only that account's authorized projects.

A Revamp account and available credits are required for generation and refinement. Plan features and pricing are available at https://revamp.dev/pricing/.

## Try it

- “Create a modern one-page website for my law firm.”
- “Redesign my website at [public URL] to improve its design and conversion experience.”
- “Build a client portal where customers can sign in and see their project updates.”
- “Show my recent Revamp projects.”

## Available tools

- `start_new_website`: Create a website from a description.
- `start_website_redesign`: Redesign an existing public website.
- `start_web_app`: Create a web app.
- `check_project`: Check progress and retrieve the latest available preview.
- `refine_project`: Request changes to an existing project.
- `list_projects`: Find existing projects.
- `list_clients`: Find authorized client workspaces where applicable.

Generation continues in Revamp while the assistant checks progress. Reuse the project identifier for follow-up changes. A preview is not a published website; publishing and domain settings remain available in Revamp.
