# Job Alerts

Open US internship and new-grad roles, read from employers' own career sites,
as read-only MCP tools. Each role carries its track, level, location, visa
sponsorship reading, citizenship or clearance restriction and graduation window.

- Endpoint: `https://recruiting.herakraft.co/mcp` (Streamable HTTP), no key needed
- Docs: https://recruiting.herakraft.co/developers/docs/mcp
- Source of the listing manifests: https://github.com/Heracraft/job-alerts-mcp

Tools: `search_roles`, `get_role`, `list_tracks`, `list_groups`,
`list_companies`, and `recent_changes` (paid Realtime key).
