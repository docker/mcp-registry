# SocialBu

Connect to the hosted SocialBu MCP server at `https://socialbu.com/mcp` using Streamable HTTP and OAuth. Sign in to SocialBu in your browser and authorize your account.

Use SocialBu to create and schedule posts, manage connected accounts and queues, read analytics, work with automations, manage inbox conversations, and browse social listening items. Available tools and data depend on your SocialBu account, plan, and permissions.

A SocialBu account is required. SocialBu offers a 7-day free trial; continued use requires a paid plan. See [pricing](https://socialbu.com/pricing).

- [Connection guide](https://socialbu.com/mcp-server)
- [Official agent package](https://github.com/socialbu/socialbu-agent)
- [Support](https://socialbu.com/contact)

Tools are discovered dynamically after authorization. No local server or Docker image is required.
