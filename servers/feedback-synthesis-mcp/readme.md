# Feedback Synthesis MCP

Customer feedback aggregation and synthesis MCP server. Aggregates feedback from GitHub Issues, Hacker News discussions, and App Store reviews to surface actionable insights for product teams.

[Documentation](https://github.com/sapph1re/feedback-synthesis-mcp)

## Tools

- **synthesize_feedback** — Synthesize feedback from multiple sources into structured summary with themes, sentiment, and key quotes
- **get_pain_points** — Extract top user pain points ranked by frequency and severity
- **search_feedback** — Search across aggregated feedback for specific topics
- **get_sentiment_trends** — Analyze sentiment trends over time for a product

## Authentication

This server uses [x402](https://x402.org) micropayments for pay-per-use access (USDC on Base network). No subscription or account required — pay only for what you use.
