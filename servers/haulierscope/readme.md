# HaulierScope

Docs: https://haulierscope.co.uk/developers

Connect to the hosted Streamable HTTP endpoint at https://haulierscope.co.uk/mcp. No account, API key or OAuth is required. The server provides 15 read-only tools for Great Britain operator licences, operators, operating centres, weekly DVSA changes and traffic-area statistics. Responses include their source and DVSA file date; this is published register data, not a live DVSA feed.

The JSON API and MCP tools are free. Optional paid licence monitoring is a separate website service and is not required to use this endpoint.

Official connector documentation: https://github.com/StoicEnso/haulierscope-mcp
