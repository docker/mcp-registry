# Flux LinkedIn MCP Server

Flux is a hosted MCP server for LinkedIn intelligence. Connect it to an MCP client and ask about the posts and engagement of any public LinkedIn profile or company page.

- Endpoint: `https://www.fluxgraph.app/mcp` (streamable HTTP)
- Documentation and setup: https://www.fluxgraph.app/features/mcp
- Agent skill and docs repository: https://github.com/elegant-atomics/linkedin-mcp

## What it does

- Audit posting patterns: which days, hours, formats, and lengths beat an account's own baseline, with sample sizes.
- Research any public account: your own, a client's, a prospect's, or a competitor's.
- Paid plans add full post history, weekly refresh, trends over time, search, and the engagement graph.

Flux is read-only on LinkedIn. It cannot publish, like, comment, connect, or message. You do not give Flux a LinkedIn password or cookie.

## Authentication

Two preview tools work without an account (subject to a daily budget). Account tools use OAuth sign-in with a free Flux account.
