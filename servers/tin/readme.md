# Tin

[Tin](https://tin.computer/) is an open-source marketing system for coding agents.

Connect to the hosted MCP server at `https://app.tin.computer/mcp` and authenticate
with your Tin account through OAuth. Tools are discovered dynamically, and access
is checked against your project membership. Workflows depend on project setup,
connected services, and available account resources.

[Documentation and connection instructions](https://github.com/tin-computer/tin#quick-start)
