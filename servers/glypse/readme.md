# Glypse MCP Server

[Glypse](https://glypse.ai/mcp-server) is an analytics and research platform for prediction markets. Its MCP server provides access to market data and research tools for investigating events and comparing markets.

## Connection

| Setting | Value |
| --- | --- |
| Server URL | `https://mcp.glypse.ai/` |
| Transport | Streamable HTTP |
| Authentication | OAuth with a Glypse account |

Create a [Glypse account](https://glypse.ai/sign-up) before connecting. Sign in and approve access when prompted. Tools are discovered after authorization.

See the [MCP server documentation](https://glypse.ai/help/mcp-server) for setup instructions and tool usage.
