# Agency Handy

Agency CRM for client projects, tasks, invoices, and proposals.

- Website: https://agencyhandy.com
- Documentation & setup: https://github.com/AgencyHandy/agencyhandy-mcp
- Endpoint: `https://mcp.agencyhandy.com/mcp` (streamable-http)

Authentication: sign in with Agency Handy (OAuth 2.1), or send `Authorization: Bearer <workspace API key>` (Settings → Workspace Config → API Key).
