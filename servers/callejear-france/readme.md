# Callejear France

Documentation: https://callejear.fr/mcp/

Remote Streamable HTTP endpoint: https://callejear.fr/api/mcp

No account, API key, or OAuth is required. Five read-only tools search communes and street records, retrieve street context, and compare 2–5 streets. The published snapshot contains 2,192,808 street records across 101 French departments.

BPE amenity counts are aggregated at IRIS level and GASPAR codes at commune level; they are not walking-radius counts or parcel-level risk assessments. Missing values and unavailable source dates are explicit. This is a snapshot, not a real-time feed.

Limits: 30 tool calls per minute and 100 per day per origin, plus 1,000 globally per day. See the documentation for current coverage, limitations and source information.
