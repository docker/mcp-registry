NUM is a travel places directory operated by 5arz Inc. It covers 2,529,721 places
across 77 destinations in 38 countries, with five tools: search places, get a place,
submit a business, submit a promotion, and list your submissions.

Get a free API key with a single POST — no card, instant:
https://itsnum.com/api/agent/signup

Tool discovery is open, so `tools/list` works without credentials. Reads are metered
per day by tier (free tier: 100/day); writes are unlimited on every tier. Business and
promotion submissions are reviewed by a person before travellers see them.

Agent platform docs: https://itsnum.com/agents/
MCP Registry listing: com.itsnum/num
