# INE Evidence

Encuentra series del INE y presenta sus cifras con periodo, unidad, definición y límites de comparación.

Runs the product's bounded, read-only official-source tools through a local
stdio MCP process. Includes a clearly dated offline example and text reports.
No account, API key, host volume, subscription or model connection is required.
Live official-source queries require outbound HTTPS. An unavailable or partial
source is not an empty search, certification or guarantee.
