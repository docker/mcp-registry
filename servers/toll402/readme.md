# Toll402

One remote MCP server with 2,600+ pay-per-call tools for AI agents: web and PDF reading, structured extraction, provenance (human vs synthetic), trusted lookup with citations, a 4.6M-business verified directory, 50+ national ID validators, community-forged tools and 2,400+ provider API endpoints (SEO, social, enrichment, ads, market data, AI generation).

Two ways to pay, same prices: prepaid credits bought by card at https://toll402.dev/credits (send the key as the `x-toll402-key` header on the connection) or USDC on Base via x402 (send x402 payment headers). Charged only on success.
