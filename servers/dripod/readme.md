# Dripod MCP Server

**Dripod** puts a print-on-demand design on 3D product mockups and returns a PNG for an Etsy, Shopify or Printify listing: 174 products — T-shirts, hoodies, mugs, tumblers, hats, totes, phone cases, pillows, socks and more — drawn with real light by Drint's render engine, the print following the fabric or the curve of the mug.

Tools: `list_products` (each product with its blank colours and page), `pod_mockup` (a design on one product in one colour → PNG). Both are read-only and need no sign-in or API key. Free pictures are up to 1024 px with a light watermark grid.

Docs: https://github.com/drint-io/dripod-mcp · Website: https://drint.io/dripod
