# Open Economics

Open Economics is a free, public, read-only MCP server for official Brazilian economic data. Its 19 tools let agents discover the right dataset in Portuguese or English, inspect source dimensions and methodology, and retrieve observations while preserving official identifiers, units, reference periods, raw values, and provenance.

No account or API key is required. The server covers Banco Central do Brasil, IBGE, Tesouro Nacional, MDIC Comex Stat, ANP, EPE, MTE Novo Caged, and CVM.
