Precleared is a hosted MCP server (streamable HTTP, no sign-in needed). It answers one question per address: may a cold or marketing email be sent to this person? Two tools: `contact_check` returns the verdict (ok_to_email, consent_needed, blocked or unknown), the rule that decided it with its legal source, what the footer must include and a signed receipt id; `verify_receipt` fetches a receipt later. Covers the UK, US, Canada, Germany, France, Australia, Ireland and the Netherlands. Free allowance of 100 checks a day per network address; an optional key (Authorization: Bearer) adds prepaid checks. Rules with sources: https://precleared.dev/rules. Weekly accuracy run: https://precleared.dev/accuracy. Server package source: https://github.com/gabrielaoimevbore-beep/precleared-mcp
