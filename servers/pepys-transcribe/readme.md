# Pepys Transcribe

Pepys Transcribe turns recordings into timestamped transcripts and lets agents search and export them. Use it for audio, video, and podcast episodes.

The hosted server uses Streamable HTTP at `https://pepys.co/api/mcp` and requires a Pepys account through OAuth. Transcription uses Pepys credits. See the [MCP documentation](https://pepys.co/mcp) for supported sources and setup.
