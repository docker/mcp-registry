# Noveum

Connect to Noveum to inspect AI agent traces, manage evaluation datasets, run evaluations, and test voice agents.

[Setup and authentication](https://noveum.ai/en/docs/platform/mcp-server-reference)

Use `https://noveum.ai/api/mcp` with Streamable HTTP. Sign in to Noveum with OAuth 2.1 and choose an organization. A Noveum account is required; usage limits and paid plans apply.
