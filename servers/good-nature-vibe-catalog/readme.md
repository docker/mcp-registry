# Good Nature Vibe Catalog MCP server

Public, read-only MCP server for product discovery and published shop knowledge. It has no accounts, carts, orders, payments or checkout.

- Documentation: https://goodnaturevibe.com
- Repository: https://github.com/aiagentcycle/gnv-catalog-mcp
- Official Registry: `com.goodnaturevibe/catalog`
- Endpoint: https://catalog-mcp.goodnaturevibe.com/mcp
- Authentication: none
- Transport: Streamable HTTP
