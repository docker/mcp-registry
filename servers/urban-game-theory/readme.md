# Urban Game Theory — Consensus Builder

Docs: https://github.com/Poglavar/consensus-builder/blob/colosseum-worlds-fair/docs/mcp-editing.md

Inspect real parcels; draft buildings, roads, parks and layouts; edit plans; compare alternatives; and share 2D/3D designs.

Remote endpoint: https://urbangametheory.xyz/mcp (Streamable HTTP). No authentication, API key, local container or paid account is required by this server. Hosted tools never sign wallet transactions or make payments. Publishing public content requires explicit confirmation; private drafts are temporary.

Feedback and security reports: https://urbangametheory.xyz/feedback.html

Server source: https://github.com/Poglavar/consensus-builder/tree/colosseum-worlds-fair/backend/agents (Apache-2.0).
