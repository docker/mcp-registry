# HelpMyAgent

HelpMyAgent provides agent-ready French company and procurement data APIs through a remote MCP server.

MCP endpoint:

https://api.helpmyagent.com/mcp

Public documentation:

https://helpmyagent.com

OpenAPI:

https://api.helpmyagent.com/openapi.json

The MCP server supports dynamic tool discovery. Business tools are paid per request using x402 on Base with USDC.
