# Comunicate.eu

[English](#english) · [Română](#română)

## English

Remote MCP server for Comunicate.eu, a Romanian platform for publishing press releases, advertorials and SEO articles on a catalogue of 3,800+ online publications.

Docs: https://comunicate.eu/en/mcp

### What you can do

This catalog entry connects without an account:

- Search the catalogue and compare prices by campaign type
- Read each publication's rules and the requirements of each campaign type
- Build budget plans by niche, topic and city

Balance, drafts and orders need a Comunicate.eu account and are refused without sign-in. The MCP guide above explains how to connect an account.

### Example prompts

- How much does an advertorial cost on a Romanian news site?
- I have a travel website and 500 lei. Where can I publish 5 articles with a dofollow backlink?
- I run a dental clinic in Cluj and have a budget of 2,000 lei. Which sites do you recommend?
- Where can I publish a press release online, and what must it contain to be accepted?

### Connection

- URL: https://app.comunicate.eu/mcp
- Transport: Streamable HTTP
- Authentication: none for the catalogue tools

## Română

Server MCP la distanță pentru Comunicate.eu, o platformă românească pentru publicarea de comunicate de presă, advertoriale și articole SEO într-un catalog de peste 3.800 de publicații online.

Documentație: https://comunicate.eu/ro/mcp

### Ce poți face

Această intrare din catalog se conectează fără cont:

- Cauți în catalog și compari prețurile pe tip de campanie
- Citești regulile fiecărei publicații și cerințele fiecărui tip de campanie
- Faci planuri de buget pe nișă, subiect și oraș

Soldul, ciornele și comenzile cer un cont Comunicate.eu și sunt refuzate fără autentificare. Ghidul MCP de mai sus explică cum conectezi un cont.

### Exemple de întrebări

- Cât costă un advertorial pe un site de știri din România?
- Am un site de turism și 500 de lei. Unde pot publica 5 articole cu backlink dofollow?
- Am o clinică stomatologică în Cluj și un buget de 2.000 de lei. Pe ce site-uri îmi recomanzi să public?
- Unde pot publica un comunicat de presă online și ce trebuie să conțină ca să fie acceptat?

### Conectare

- Adresă: https://app.comunicate.eu/mcp
- Transport: Streamable HTTP
- Autentificare: niciuna pentru uneltele de catalog
