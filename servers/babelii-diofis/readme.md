# Babelii-Diofis

Buy phone credit, data packages, PLN electricity tokens, bills, e-wallet top-ups and game vouchers in Indonesia through an AI agent. Search, prepare an order, confirm, then pay through a payment link. No sign-in needed.

Endpoint: https://babelii.diofis.net/mcp/commerce/ (Streamable HTTP, no sign-in required).

Operator: Diofis Enterprise / PT Data Infra Ekselen. The same server is published in the official MCP Registry as `net.diofis/babelii`.
