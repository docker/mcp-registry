TaskLite (tasklite.net) is a hosted backend with an admin the business runs
itself. One `build_backend` call turns a described system into a project with
typed boards, relations, rows, REST endpoints and a server-side key; the same
boards are immediately a kanban, a calendar, forms, approvals and automations.

Not to be confused with the unrelated TaskLite command-line task manager at
tasklite.org.

Sign in with OAuth (dynamic client registration, PKCE) or a `tl_` API key.
Examples with the exact prompts and live results: https://tasklite.net/proof
