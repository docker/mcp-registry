# Drisp MCP Server

**Drisp** puts a screenshot of an app or website on a 3D device mockup and returns a PNG. Devices include every iPhone from 12 to 18 Pro, iPads, a MacBook, Apple Watch, Galaxy and other Android phones, a laptop and a monitor, rendered in 3D with real glass and light.

Tools: `list_devices` (each device with the screenshot size in pixels that fills its screen exactly) and `device_mockup` (a screenshot as a public https link or base64 PNG / JPEG / WebP up to 10 MB, placed on a device; returns a PNG link kept for 1 hour). Both are read-only and need no sign-in or API key.

Free pictures are up to 1024 px with a light watermark grid, about 20 an hour per address; clean and larger pictures come with Drisp Pro on the website.

Docs: https://github.com/drint-io/drisp-mcp · Website: https://drint.io/drisp
