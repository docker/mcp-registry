Docs: https://invokely.ai/docs/

The configured endpoint uses Invokely's anonymous trial, limited to 25 calls per day per IP address. For authenticated MCP access, use https://invokely.ai/mcp with an API key.

The hosted service backend is not included in the public source repository. The separate MIT repository at https://github.com/estevecastells/invokely-mcp-connector contains a local stdio adapter for the hosted service.
