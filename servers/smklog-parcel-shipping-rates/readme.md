# SMKlog Parcel Shipping Rates

Remote MCP server (Streamable HTTP, no authentication) that prices parcel shipping from the United States, domestic and to Canada, the United Kingdom, Germany and Australia, from a plain-words description of the item. Five tools: `get_parcel_quote`, `create_checkout_link`, `get_checkout_status`, `track_parcel`, `get_price_index`.

- Documentation: https://smklog.com/api
- Endpoint: https://quote-api.smklog.com/mcp
- Tool definitions and source: https://github.com/smklog/parcel-shipping-rates-mcp
