# geolint

ESLint for AI search. Audits whether websites are discoverable and citable by AI answer engines: robots.txt evaluated across 51 AI crawler tokens, llms.txt validation, structured data and citability — 52 rules with a 0–100 score and a fix per finding.

- Repository: https://github.com/iliasabk/geolint
- Docs: https://iliasabk.github.io/geolint/
- npm: https://www.npmjs.com/package/@iliasabk/geolint

Tools: `audit_url`, `compare_urls`, `generate_llms_txt`, `list_rules`, `list_ai_bots`. No secrets or configuration required.
