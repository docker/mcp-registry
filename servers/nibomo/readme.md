Docs: https://nibomo.com/docs/mcp-connector/

[Nibomo](https://nibomo.com) is an open-source flashcards app for spaced-repetition learning. Its [hosted MCP server](https://mcp.nibomo.com/mcp) lets AI assistants create and review flashcards.

A Nibomo account is required. Sign in with an email one-time code, then authorize access through OAuth. Reviewers can use their own email and account; no shared credentials are needed. Tools are discovered dynamically after authentication.
