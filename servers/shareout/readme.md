Shareout publishes self-contained HTML documents with named expiring links,
version history, and reviewer comments. Sign in with a Shareout account through
OAuth to connect. The server uses Streamable HTTP and dynamic tool discovery.

Document bytes never belong in MCP arguments. Hosted publishing returns a direct
HTTP upload URL; a client needs file-transfer capability to upload the document
before committing publication. Clients without that capability can use the
standalone Shareout CLI or local MCP instead. Native ChatGPT HTML attachments
are also supported in ChatGPT.
