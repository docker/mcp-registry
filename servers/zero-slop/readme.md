# Zero Slop

Zero Slop scores and rewrites AI-assisted prose while preserving source facts. The remote MCP server returns the edited text with before and after writing scores, flagged-phrase counts, and source-preservation checks.

No account or API key is required. Drafts are processed in memory, are not logged or stored, and are excluded from telemetry.

## Tools

- `deslop`: Rewrite a complete draft for clearer, more natural prose. Accepts an optional genre and audience.
