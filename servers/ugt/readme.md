UGT (Use the GitHub Thing) gets GitHub projects running on your own computer, with your AI app. Give your AI app any GitHub link and the job you want done: UGT gets the project running in a private Linux engine of its own, proves the job worked on a known sample before it touches your files, and hands you the result. Windows, Mac or Linux, with no Docker to learn and no cloud bill.

UGT's hosted MCP server is how any AI app starts with UGT. It finds how UGT runs a GitHub project, from the recipes people have shared, shows exactly what a recipe runs, takes and can reach, and gives the one line that installs UGT on your computer, where the work runs.

Connect to https://mcp.usegithubthing.com/mcp using streamable HTTP. It is free and read-only and needs no authentication.

Source repository: https://github.com/auscaster/ugt
