Docs: https://github.com/norman-finance/norman-mcp-server#readme

Norman connects invoicing, transactions, receipts, bookkeeping, financial reports,
and tax workflows to your AI assistant. German capabilities include DATEV,
ELSTER, and GmbH/UG workflows.

A [Norman account](https://app.norman.finance/sign-up) is required. Connect to
`https://mcp.norman.finance/mcp` using Streamable HTTP and authorize access through
Norman OAuth. Tools are discovered dynamically after authentication; no local
server or Docker image is required.
