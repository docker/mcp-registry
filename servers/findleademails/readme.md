Find and verify B2B work emails from your AI agent. Single lookups, bulk lookups, and async jobs. A verified result costs 1 credit. Catch-alls, misses, and repeat lookups are free.

Set your FindLeadEmails API key as the `findleademails.api_key` secret. It is sent as the `Authorization: Bearer <key>` header. Create the key on the Developers page after you sign in.
