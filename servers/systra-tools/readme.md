# Systra Tools

Official documentation: https://systra.tools/mcp?utm_source=docker_mcp_catalog&utm_medium=referral&utm_campaign=mcp_directory

Remote MCP endpoint: https://systra.tools/api/mcp

Systra Tools provides ready-to-use React and Tailwind sections and elements for coding agents. Free components are available without authentication. For optional Premium access, configure an API key as documented on the official site.

Source and installation instructions: https://github.com/systra-tools/systra-tools-plugin
