Newsflash is a hosted MCP server (Streamable HTTP) at https://newsflash.sh/mcp.
No local install is needed — the keyless test tier works instantly (50 req/day
per IP, 24h lookback). An optional API key (`Authorization: Bearer nf_…`,
obtained via email one-time code) raises limits and history depth. Also listed
in the official MCP registry as `sh.newsflash/newsflash`.
