# Driglass MCP Server

**Driglass** is for packaging printed straight on glass (ceramic screen print / applied ceramic label, not a paper label): beer and wine bottles and drinking glasses at real sizes from makers' sheets.

Tools: `list_containers` (each bottle and drinking glass with its size, finish and print zones), `print_spec` (for one container, its glass colour and its inks: the art size of each zone, the neck unrolled to its arc, the screens needed and the rules for enamel on glass). Both are read-only and need no sign-in or API key.

Docs: https://github.com/drint-io/driglass-mcp · Website: https://drint.io/driglass
