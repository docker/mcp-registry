# MCPBinder

Connect to the hosted MCPBinder server at https://www.mcpbinder.com/api/mcp using Streamable HTTP and OAuth. The server supports dynamic client registration and advertises its authorization metadata through standard MCP OAuth discovery.

An MCPBinder account and workspace access are required. Public sign-up is available for adults 18 or older based in the United States. During authorization, choose the workspace, projects, permissions, and expiry. Access can be reduced or revoked in MCPBinder's Agent access settings. No credentials are included in this catalog entry; the OAuth credential fields follow the catalog's remote-server convention.

Read project goals, tasks, decisions, and recent activity; plan tasks and record updates when authorized. Task writes and comments are attributed to the agent connection. The hosted server discovers tools dynamically, so tools.json is intentionally empty.
