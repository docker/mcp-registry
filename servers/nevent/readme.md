# Nevent MCP

Talk to your live-events CRM (campaigns, analytics, paid ads, segments, short URLs) in Claude and ChatGPT.

Official remote MCP server for [Nevent](https://nevent.ai/en) — the marketing platform for live event promoters. Hosted with OAuth 2.1; 50+ tools across campaigns, analytics, segmentation, paid media, deliverability and short URLs.

- **Documentation:** https://help.nevent.ai/en/nevent-ai/
- **Endpoint:** `https://mcp.nevent.ai/mcp` (streamable-http)
- **Source:** https://github.com/nevent-dev/mcp-nevent
