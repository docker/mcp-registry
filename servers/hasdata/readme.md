# HasData

Web scraping and structured web data over the Model Context Protocol. One remote endpoint exposes tools for Google, Bing and DuckDuckGo SERP, Google Maps, Trends and Flights, plus Amazon, Zillow, Redfin, Airbnb, Booking.com, Yelp, Indeed, Glassdoor, Instagram, TikTok, YouTube, and any public URL. Every tool returns parsed JSON.

Get a free API key at https://app.hasdata.com and send it in the `x-api-key` header.

Documentation: https://docs.hasdata.com/mcp-server
