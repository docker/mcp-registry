# срезAI Web Access

Hosted MCP server for AI agents: web and news search, page reading as clean Markdown, site maps, section crawl, structured extraction by JSON schema, claim verification with quotes, YouTube transcripts and WebMCP.

- Endpoint: `https://srezai.ru/api/mcp` (Streamable HTTP)
- Auth: API key as `Authorization: Bearer srz_live_...`; keys are created in the dashboard at https://srezai.ru/dashboard
- Anonymous trial: 25 requests/day per IP (search, read and transcripts) - enough to test the server without an account
- Docs: https://srezai.ru/docs/mcp
- How to choose between MCP, CLI and REST API: https://srezai.ru/connect
- Official MCP Registry: `ru.srezai/search`
