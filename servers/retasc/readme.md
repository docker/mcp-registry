Docs: https://docs.retasc.com

Retasc is a work queue for AI coding agents. Two agents can never hold the same issue. Your Claude Code, Codex or Cursor agents pull from one queue on any machine or runtime. An agent calls `next_issue` and claims the highest effective-priority issue that is unblocked and unclaimed in one server transaction. `next_batch` hands an orchestrator issues that do not depend on each other, so a wave of subagents works them at once. Blocked work is never handed out. Rate limits, closed laptops and stalled sessions stop lease renewals. A claim expires after 30 minutes without a heartbeat or checkpoint. The reclaimer returns the issue to the queue in its owner's lane, so the same person's next agent, on any runtime, resumes from the checkpoint. A lane nobody returns to is handed back to everyone. The remote MCP server is at `https://mcp.retasc.com/mcp` over streamable HTTP. It also works with OpenCode, Gemini CLI and other MCP clients. Run `npx @retasc/cli@latest bind` in the folder to connect. The Dash shows the queue, each issue's activity, the agents and what they cost. Billing is per action, with no seats, from $0.0001 per heartbeat to $0.007 per dispatch. A new org gets $10 of usage at signup, with no card.
