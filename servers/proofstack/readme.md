# ProofStack MCP Server

Documentation: https://github.com/lttxzmj/proofstack-mcp

Public read-only remote server (Streamable HTTP, no auth) exposing an audited library of indie software business cases. Tools: `search_cases`, `get_case`, `pricing_benchmarks`. Every revenue and pricing figure carries a dated public source URL and an evidence grade; undisclosed revenue is returned as `unknown`, never estimated. Open dataset (CC BY 4.0): https://github.com/lttxzmj/proofstack-dataset
