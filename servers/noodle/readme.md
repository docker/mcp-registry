Noodle Biomedical Literature Discovery MCP 0.2.1 exposes seven public,
read-only tools for biomedical paper search, publication details, bounded
citation or semantic literature-graph traversal, and opt-in Helena support.
It accepts no patient records, PHI, private cases, credentials, or uploads.

Docs: https://noodle.helena.bio/integrations
Source: https://github.com/helena-bioinformatics/noodle-mcp
