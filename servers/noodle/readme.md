Noodle Biomedical Literature Discovery MCP 0.2.0 exposes six public,
read-only scientific tools for biomedical paper search, publication details,
and bounded citation or semantic literature-graph traversal with provenance.
It accepts no patient records, PHI, private cases, credentials, or uploads.
