# Calculate Pool

Does the swimming pool math owners ask about most, with the same formulas as calculatepool.com: how many gallons a pool holds from its shape and size (rectangle, round, oval, Roman, Grecian, kidney, L-shape or freeform, sloped floors and above-ground wall heights, feet or metres), how much chlorine, salt, baking soda, muriatic acid, stabilizer or calcium chloride to add, the pump flow for a turnover time and the heater size in BTU per hour. It works with numbers only and stores nothing.

## Tools

- `pool_volume`: gallons, litres and cubic feet from shape and size
- `chemical_dose`: amount of a pool chemical to move a reading to a target
- `pump_size`: pump flow, horsepower range and minimum filter area for a turnover time
- `heater_size`: heater BTU per hour for a temperature rise in a set time
- `pool_facts`: standard pool sizes in gallons by wall height or depth

All tools are read-only. The server is public: no account, no login and no API key.
