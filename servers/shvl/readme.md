# SHVL

Review overdue invoices, synced Xero invoices and contacts, and live Xero reports. Read-only.

Published by Studea.

Docs: https://shvl.app/cli

## Access

Sign in and select an authorised workspace. Standard tools are read-only. Xero reads require the workspace owner and provider connection. Live Profit and Loss, Balance Sheet and Trial Balance reports require report permission and explicit dates; invoice/contact searches use the latest completed sync. An active trial or subscription is required. Creating reviewed Xero drafts requires a separately approved write connection and approval of the exact action. Standard MCP access cannot create, authorise, pay or send records.

Connect to `https://shvl.jlucwright.workers.dev/mcp/v2` using OAuth and approve only the access you need. No credentials belong in this catalogue entry.
