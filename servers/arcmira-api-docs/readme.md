# Arcmira API Docs

[Arcmira](https://arcmira.com) · [API documentation and quickstart](https://arcmira.com/docs)

Search the documentation for Arcmira's YouTube transcript search API, including timestamped quotes, speaker appearances, mentions, sponsors, recommendations, monitors, and TypeScript/Python SDKs.

- [OpenAPI schema](https://api.arcmira.com/v1/openapi.json)
- [Documentation MCP setup](https://arcmira.com/docs/llms)

This hosted documentation connection requires no account or API key. It searches documentation and reads documentation files. Its separate feedback tool submits feedback, so the connection is not entirely read-only.

To search actual transcript data, use the separate [Arcmira research connection](https://arcmira.com/docs/mcp-server). Research access requires an Arcmira account and has usage limits. A Premium read uses credits from your plan, then any top-up credits, then your on-demand budget.
