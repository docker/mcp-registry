# Tensorust Ontology MCP Server

Remote MCP server (Streamable HTTP) for public-records data and ontology services.

- Endpoint: `https://shop.tensorust.com/api/mcp`
- Free tier: no API key required (dataset previews and metadata)
- Full access: x402 USDC payment on Base, or `tdk_` API keys
- Official MCP Registry name: `com.tensorust/ontology`

Documentation: https://tensorust.com
Contact: mattbusel@tensorust.com
