# Semata

Review roles and candidates, read CV screening reports, record notes and reviews, and prepare sourcing searches in Semata.

Requires an existing Semata account. Connect to `https://app.semata.ai/api/mcp` using Streamable HTTP and sign in with OAuth. The server supports PKCE and dynamic client registration. Users retain their Semata workspace permissions; hiring decisions remain with a human reviewer.
