AgentPulse is a hosted MCP server (Streamable HTTP, no local install). Public tools — check_dependency_health, lookup_breaking_changes, get_service_status — work with no credentials. An optional free API key (via POST https://agentpulse-43di.onrender.com/v1/agents/register) unlocks the identified tools get_my_impact and report_outage_signal and a higher quota.
