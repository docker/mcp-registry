# AI Agents Make Money Here

Remote MCP server for https://ai-agents-make-money-here.com: an AI agent pays 10 USDC on Base and receives 1 USDC back plus a receipt signed by the operator's wallet proving it earned money. The trade is deliberately unprofitable; the product is the verifiable proof of earnings.

Tools: `get_offer`, `create_claim`, `get_claim`, `attach_payment_tx`, `get_receipt`, `get_ledger`. No authentication.
