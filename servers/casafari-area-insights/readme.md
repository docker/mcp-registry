# Casafari Area Insights

Casafari is the AI agent-native real estate data intelligence platform. Deduplicated, cleaned property graph. Europe's most complete property index.

Asking-price and price-per-m² series over time with growth and volatility, distributions by price, bedrooms and time on market, and heatmaps by district.

## Access

One of the per-product MCP servers of the Casafari API and MCP Platform. Sign up at https://platform.casafari.com/console/ (Free plan, no card). The server uses OAuth 2.1 with PKCE (dynamic client registration and client ID metadata documents); your MCP client signs you in with your platform account.
