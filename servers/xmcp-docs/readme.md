Docs: https://xmcp.dev/docs/guides/xmcp-mcp-server

The official xmcp documentation server exposes a read-only `search` tool that accepts a query or page ID. Connect to `https://xmcp.dev/mcp` using Streamable HTTP. No authentication is required.

Source: https://github.com/basementstudio/xmcp/tree/main/apps/website (MIT).

Security contact: https://github.com/basementstudio/xmcp/blob/main/SECURITY.MD

This entry is for the hosted Docs server. The `xmcp` npm package is the framework used to build MCP servers, not an executable package for this hosted service.
