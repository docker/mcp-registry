# SaaS Pro Max

[Documentation](https://saaspro.dev/docs/mcp) | [Connect an assistant](https://saaspro.dev/connect)

Connect the hosted Streamable HTTP endpoint using OAuth with dynamic client registration and PKCE S256. Sign in to SaaS Pro Max, verify a passkey, and select one organization and an access level. Read access is sufficient for reports. Tool access follows the current organization role, approved scopes, enabled modules and personal-data permissions.

A free SaaS Pro Max workspace is available. Individual features depend on the workspace plan and permissions. Protected operations retain member approval requirements.
