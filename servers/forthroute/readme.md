Docs: https://app.forthroute.io/docs/ai-connector

ForthRoute is a free returns app for Shopify. After a merchant signs in with OAuth, an agent can search returns, get an overview of open returns, open a single return, and approve or decline it. approve_return and decline_return change the return in ForthRoute.

Endpoint: https://app.forthroute.io/mcp (Streamable HTTP)
Auth: OAuth (returns:read, returns:write) for every tool
