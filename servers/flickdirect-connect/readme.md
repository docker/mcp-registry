FlickDirect Connect is FlickDirect Inc.’s free, public, read-only Movie MCP Server, built on the open Model Context Protocol standard. It provides movie and TV facts, country-specific release dates and ratings when available, entertainment and CinemaCon coverage, podcasts and deals, with brief previews or summaries and original source-page links.

Connect using Streamable HTTP at https://connect.flickdirect.com/mcp. No FlickDirect account, OAuth, API key or subscription is required. The hosted implementation remains proprietary. This catalog entry contains connection metadata only and does not license or distribute service source, full editorial content or third-party photographs.
