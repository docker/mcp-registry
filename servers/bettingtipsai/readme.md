# Betting Tips AI (remote MCP)

Documentation: https://bettingtipsai.com/docs

Remote Streamable HTTP endpoint: https://bettingtipsai.com/api/mcp

Sign in with a free Betting Tips AI account (email code, Google, or Apple). OAuth 2.1 with dynamic client registration. Rate limits: 30 requests per minute and 500 per day per account.

Read-only tools: list_today_tips, get_match_tip, list_leagues, list_recent_results.

Informational tips only, for users aged 18 or over. The server does not place bets or return affiliate links.
