# Bigdata.com

Bigdata.com brings institutional-grade financial research to AI agents: SEC filings, earnings call transcripts, broker research, financial statements and estimates, company and market tearsheets, corporate events calendars, and premium news — all grounded with source citations through RavenPack's financial knowledge graph.

Built for financial analysts, hedge funds, asset managers, and investment banks who need agents that can research companies, track events, and answer questions with verifiable sources.

## Getting an API key

To use this MCP server, generate a personal API key at [platform.bigdata.com/api-keys](https://platform.bigdata.com/api-keys), then set it as the `bigdata.api_key` secret when enabling this server in Docker Desktop.
