# VetAI

The pet-care MCP server for AI assistants: live vet search, 24-hour emergency routing, clinic details, booking handoffs, and pet product search.

- Website: https://usevetai.com
- MCP endpoint: https://usevetai.com/mcp (Streamable HTTP, no authentication)
- Official MCP Registry: `com.usevetai/vetai`
- Source: https://github.com/lokman910/vetai
