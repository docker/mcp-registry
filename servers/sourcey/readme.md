Sourcey's hosted research MCP helps agents find and compare startup credits and offers, inspect dated source evidence and eligibility conditions, track changes, and read Agent Readiness report cards. Its public tools also prepare readiness declarations and describe Sourcey's paid services; paid work uses a separate flow.

Connect to https://mcp.sourcey.com/mcp using streamable HTTP. Public research requires no authentication. Reports retain their source evidence, observation dates and unresolved conditions so callers can assess freshness and applicability.

Sourcey is one project dating to 2016. Its open-source documentation engine is documented at https://sourcey.com/docs; this MCP entry covers the hosted research tools.
