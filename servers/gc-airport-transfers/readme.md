# GC Airport Transfers

Private fixed-price transfers for Gold Coast (OOL) and Brisbane (BNE) airports and the Brisbane International Cruise Terminal.

- **MCP endpoint (streamable HTTP):** https://gc-airporttransfers.com/wp-json/atb-gateway/v1/mcp
- **Docs:** https://gc-airporttransfers.com.au/ai-agent-gateway/
- **Official MCP Registry:** `com.gc-airporttransfers/booking` (v2.3.16)
- **Auth:** OAuth 2.1 with PKCE, Dynamic Client Registration and Client ID Metadata Documents; scope `transfers`
- **Tools:** `get_service_info`, `get_quote` (MCP Apps quote card UI), `check_availability`, `request_booking` (pending requests; operator confirms; payment by emailed link)

Docs: https://gc-airporttransfers.com.au/ai-agent-gateway/
