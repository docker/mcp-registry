# Council of AI GSPC — measurement over MCP

Deterministic governance-measurement server: run a subject through the frozen GSPC axis set (13 of 14 measured), every result is an Ed25519-signed, offline-verifiable measurement card. No model in the verification path; UNMEASURED is reported, never hidden.
