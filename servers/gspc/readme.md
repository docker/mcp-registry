# Council of AI GSPC — measurement over MCP

Deterministic governance-measurement server. Quote `totals.public_count` from `GET https://councilof.ai/api/gspc` (living board: 22 axis · 15 measured; 7 slots empty). Every result is an Ed25519-signed, offline-verifiable measurement card. No model in the verification path; UNMEASURED is reported, never hidden. Measurement, not certification.
