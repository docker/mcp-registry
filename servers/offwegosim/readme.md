OffWeGoSIM provides a public Streamable HTTP MCP endpoint at https://offwegosim.com/mcp. No authentication or API key is required.

Tools: `search_plans`, `get_plan`, and `get_checkout_link`.

MCP access is free. Travel eSIM plans are paid purchases; customers review and complete checkout on OffWeGoSIM. The server cannot create orders, charge cards, issue eSIMs, or access customer records.
