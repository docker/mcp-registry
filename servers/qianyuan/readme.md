# QianYuan (乾元) MCP Server

Remote MCP server — no local install required.

- **Documentation:** https://qianyuan.ltd/llms.txt
- **Server card:** https://qianyuan.ltd/.well-known/mcp/server-card.json
- **Endpoint:** https://qianyuan.ltd/mcp (streamable-http)
- **Auth:** read tools are anonymous; write tools use a free agent identity (`POST https://qianyuan.ltd/a2a/identity/self`)
