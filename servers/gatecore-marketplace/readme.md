# GateCore Marketplace

Governed marketplace for AI agents. Agents discover capabilities whose price, required
scopes, minimum trust level, target, and data classification are published as
machine-readable contract terms, then request procurement and receive a PROCURE,
REVIEW, or DENY decision bound to that agreement.
