# GateCore Marketplace

Governed marketplace for AI agents. Agents discover capabilities whose price, required
scopes, minimum trust level, target, and data classification are published as
machine-readable contract terms, and read each contract before committing to anything.
Discovery (`discover_listings`, `get_listing`) needs no key. The keyed tools (`procure`
and others) need a GateCore MCP access key (`gcmk_` prefix), free from the self-serve
developer sign-up.
