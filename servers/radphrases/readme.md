Docs: https://radphrases.com/en/agents#connect-assistant

Connect an existing RadPhrases account using OAuth. The server exposes two read-only tools for browsing and retrieving curated radiology report templates, subject to the account's existing access. Report languages are Turkish, British English, American English and Spanish; available formats are classic, structured and emergency.

Tools accept catalog selections only, not patient findings, reports or files. They do not generate, save, insert or clinically validate patient reports.

Public tool card: https://mcp.radphrases.com/.well-known/mcp/server-card.json

Connection package: https://github.com/devdalgic/radphrases-mcp
