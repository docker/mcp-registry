Website: https://www.palisade.email/mcp

Docs: https://developer.palisade.email/docs/guide#mcp

This entry is Palisade's no-account endpoint, with two read-only tools that read public DNS: `audit_domain` and `validate_spf_include`. Managing your own domains uses the signed-in endpoint at https://api.palisade.email/mcp (OAuth), described on the website.
