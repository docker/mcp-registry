Runheed is error tracking your coding agent can read. Your app reports exceptions through a Node or Python SDK. Errors are grouped by fingerprint with stack traces, breadcrumbs, request details (secret headers redacted) and agent context. Claude Code, Cursor, Codex, ChatGPT or any MCP client connects to https://runheed.com/api/mcp, reads what broke, fixes it and resolves the error with a note. Plans from $29/month with a 7-day trial.
