# Chorus Research MCP Server

The **Chorus Research MCP Server** connects MCP-based agents and AI assistants to Chorus Research, a survey platform for market research with human respondents. It is a hosted remote server using Streamable HTTP with OAuth sign-in (no API key).

## Features

- **Audiences** – List available target audiences (`list_audiences`).  
- **Surveys** – Create a survey (`create_survey`) and check its status (`get_survey_status`).  
- **Pricing** – Estimate survey cost (`estimate_cost`) and launch price (`estimate_launch`).  
- **No charges through MCP** – The hosted server never charges; launches return a browser checkout link.

## More Information

See the [Chorus Research MCP documentation](https://chorusresearch.io/docs/mcp).
