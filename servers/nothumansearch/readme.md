# Not Human Search

Docs: https://nothumansearch.ai

Search indexed websites, APIs, and services by agent-readiness signals, then inspect site reports.

The public Streamable HTTP endpoint is `https://nothumansearch.ai/mcp`. Search and site details require no account or API key. Tools are discovered from the endpoint at runtime.

Some tools submit URLs, register monitors, or record action interest. Use those tools only when the user requests the action. Provider actions are currently unavailable.
