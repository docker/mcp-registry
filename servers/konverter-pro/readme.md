# Konverter Pro MCP Server

**Konverter Pro** turns German bank statements and payment-provider reports into bookkeeping files that import into DATEV, Lexware or any MT940-capable accounting software.

## Features

- **Many sources** – bank statement PDFs, CSV and MT940 files, plus PayPal, SumUp and Stripe reports.
- **Verified output** – every file reports pages and records read and whether the balances reconcile; files that cannot be proven complete are never released as final.
- **Grouped questions** – bookings that need an account are grouped by type, so an agent answers each group once.
- **Free preview** – a draft or sample is free; the final file is paid per job (Stripe payment link), or covered by a Konverter Pro plan when an API key is sent as `Authorization: Bearer ...`.

## Example Use Cases

- "Convert my bank statement PDFs for January to March into a DATEV booking file (SKR03)."
- "Turn this SumUp sales report into a DATEV export and tell me which bookings still need an account."
- "Make an MT940 file from this PDF bank statement."
