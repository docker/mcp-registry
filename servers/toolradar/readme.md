# Toolradar

Verified data on 9,000+ B2B software tools for your AI assistant: fit-ranked recommendations for a described need, pricing verified weekly with the verification date, aggregated G2/Capterra ratings, side-by-side comparisons, and real alternatives. Read-only, free tier.

8 tools: recommend_tools, search_tools, get_tool, get_pricing, compare_tools, get_alternatives, list_categories, report_issue.

Documentation: https://toolradar.com/for-agents
