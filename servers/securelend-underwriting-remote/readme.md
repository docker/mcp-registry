# SecureLend Underwriting (remote)

Streamable HTTP MCP for credit desks.

- Endpoint: `https://mcp.securelend.ai/v1/lender/mcp`
- Public metadata: https://github.com/SecureLend/mcp-underwriting
- Docs: https://docs.securelend.ai/mcp/lender
- OAuth scope `lender` for `tools/call`; `initialize` / `tools/list` anonymous
- SecureLend is not a lender; no tool approves a loan

Not Market (`https://mcp.securelend.ai/mcp`).
