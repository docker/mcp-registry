# Anakin

Web data for AI agents. `scrape` any URL to clean markdown or structured
JSON, `map` and `crawl` whole sites, run AI-native `search` and multi-source
`agentic_search` deep research, execute pre-built read/write `wire_*` actions
across hundreds of popular websites, `monitor_*` pages for changes on a
schedule, compare AI answer engines with `ai_visibility_*`, and drive a real
cloud browser with `browser_task`.

- Docs: https://anakin.io/docs
- Get a free API key: https://anakin.io/dashboard (300 credits, no card)
