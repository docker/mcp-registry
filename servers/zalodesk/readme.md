ZaloDesk lets businesses manage their Zalo messaging from one place: personal Zalo accounts and Zalo Official Accounts, team permissions, customer routing, and AI voice calls.

The MCP server gives AI agents the same access the web inbox has: read and send Zalo messages, manage the team, route customers, and handle friend requests and labels — all scoped by the workspace's permission system (Phân quyền).
