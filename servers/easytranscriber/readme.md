Hosted MCP server (Streamable HTTP) for YouTube transcripts and AI summaries. Tools: `get_transcript`, `summarize_video`, `search_youtube`, `resolve_channel`, `search_channel`, `get_channel_videos`, `get_channel_latest`, `get_playlist_videos`, `get_comments`, `check_credits`.

Every tool call needs an EasyTranscriber API key, sent as `Authorization: Bearer <key>`. Free accounts can create one. Credit cost per tool: https://www.easytranscriber.com/docs/mcp#tools. Plans and prices: https://www.easytranscriber.com/pricing.

EasyTranscriber is not affiliated with YouTube or Google.
