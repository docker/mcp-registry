Forthmatch keeps a free directory of 3PL fulfillment providers in the US, Canada, the UK, Europe and Australia. An agent can search it by head-office country or Europe, service, monthly orders and Shopify integration, read one provider's profile, and send a quote request. Forthmatch forwards the request to providers from the directory that fit the volume and region, and each provider replies to the requester directly. Forthmatch is not a 3PL and does not quote itself. Details come from each company's own website; the results are not a ranking.

Endpoint: https://forthmatch.io/mcp (Streamable HTTP)
Auth: none. Every tool works without sign-in.
