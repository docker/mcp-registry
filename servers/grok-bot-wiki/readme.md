The hosted service exposes 11 tools: nine declare readOnlyHint, while submit_bot and start_checkout declare writes. submit_bot queues a public Bot share link for a human-reviewed free listing. start_checkout creates an optional paid upgrade link only after the user requests the upgrade and accepts its terms; it requires an email and terms version. The user opens Stripe to pay; the tool does not charge them.
