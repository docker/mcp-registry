# Tradehand

Find and book local tradespeople: search traders by trade and area, compare fixed prices and reviews, get instant quotes, book and pay through a secure checkout link. Tradespeople use it to manage their business.

## Configuration

Search and read tools work without sign-in. Customer tools use OAuth with dynamic client registration.
