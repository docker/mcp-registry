# Clueso

Clueso is an AI video and documentation platform. This remote MCP server lets your AI agent create on-brand videos and step-by-step guides straight from a prompt — turning screen recordings, slide decks, or documents into finished, fully editable content, without leaving chat.

- **Server URL:** https://connect.clueso.io/mcp
- **Transport:** Streamable HTTP
- **Auth:** OAuth 2.0 (sign in to Clueso)
- **Setup guide:** https://help.clueso.io/mcp-setup

Listed on the official MCP Registry as `io.clueso/video`.
