# Casafari

Casafari is the AI agent-native real estate data intelligence platform. Deduplicated, cleaned property graph. Europe's most complete property index.

## Tools

- Comparables and valuations
- Area insights: price trends, distributions, heatmaps
- Agency analysis (Germany)

## Access

Requires a Casafari account with an MCP subscription. The server uses OAuth 2.1 with PKCE and dynamic client registration; your MCP client signs you in with your Casafari account.
