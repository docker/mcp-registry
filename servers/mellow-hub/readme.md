Docs: https://www.mellow.world/hub/docs

Mellow Hub is a hosted MCP server (Streamable HTTP, OAuth 2.1 with dynamic client registration and PKCE) for publishing and scheduling posts to Instagram, TikTok, YouTube, X, LinkedIn, Threads, Bluesky, Pinterest and Facebook. Endpoint: `https://www.mellow.world/mcp`. Agent skill: https://github.com/wco1/mellow-hub-skill
