# Aisle MCP Server

[Aisle](https://aisle.wedding) is a wedding platform for couples planning weddings anywhere, with deep coverage of destination weddings. This hosted MCP server lets an AI assistant search Aisle's venue and vendor directory, estimate budgets and guest travel costs, and build planning timelines and checklists.

Public planning tools work without an account. Private wedding details (guests, events, accommodations, registry progress) require OAuth sign-in with an Aisle account, and changes require an existing Aisle membership.
