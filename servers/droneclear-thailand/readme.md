# DroneClear Thailand

Answers what a hobby or holiday drone needs in Thailand: CAAT and NBTC registration, liability insurance, flight limits and restricted areas (Bangkok, Hua Hin, Chiang Mai and others named in the CAAT airspace publication). Every rule comes with its public source and a link to the matching page on droneclearthailand.com.

## Tools

- `drone_check`: requirements for a given drone model or take-off weight, camera, location and purpose
- `how_droneclear_helps`: what the DroneClear registration service covers

All tools are read-only. The server is public: no account, no login and no API key.
