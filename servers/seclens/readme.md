Anonymous Streamable HTTP MCP server (`https://seclens.one/mcp`) and standalone Go CLI (`https://github.com/42Sec-Pte-Ltd/seclens`) for assessing any domain's email security posture across SPF, DMARC, DKIM, MTA-STS, TLS-RPT, DANE, DNSSEC, and informational BIMI. No account or API key required.
