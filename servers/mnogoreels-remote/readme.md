# MnogoReels

MnogoReels turns long videos (YouTube, VK Video, RuTube, Dzen, Twitch, Yandex Disk, Google Drive or direct links) into captioned vertical Shorts and Reels, and also makes transcripts, articles and YouTube thumbnails.

Tool calls need a personal API key: create it at https://mnogo-reels.ru/dashboard/developers?tab=keys (it starts with `mrfrt_usr_`). Listing tools works without a key.

Making clips costs 1 credit per started minute of the processed video; the server quotes the price first and refuses to spend more than the `max_credits` you allow.

Full documentation: https://github.com/RealSatanyan/mnogoreels-mcp#readme
