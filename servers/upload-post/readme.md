# Upload-Post MCP Server

Publish, schedule, analyze and manage social media across 13+ networks from any
MCP-compatible agent.

- Documentation: https://docs.upload-post.com/guides/mcp-server-integration
- Source: https://github.com/Upload-Post/upload-post-mcp (MIT)
- Get an API key: https://app.upload-post.com → API Keys

The hosted endpoint also supports OAuth 2.1 with Dynamic Client Registration if
you prefer not to configure a static API key.
