# Mitosis

Documentation: https://mitosislabs.ai/developers

Server card: https://mitosislabs.ai/.well-known/mcp/server-card.json

Mitosis gives AI agents a private, queryable memory of their user's real data: connected email, calendar, documents, contacts and chat history, indexed as one searchable knowledge graph with citations. The public tools (pricing, docs search, platform status, agent skills) need no authentication; the `cortex_*` memory tools use OAuth 2.1 with in-band sign-in (lazy auth), so the server works the moment it is added.

Also published in the official MCP registry as `ai.mitosislabs/mitosis` (domain-verified).
