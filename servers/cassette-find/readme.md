# Cassette Game Finder

Read-only browser-game discovery over Streamable HTTP at https://cassette.gg/mcp. No account or API key is required.

Tools: `search_games`, `get_game`, `similar_games`, and `list_genres`.

Documentation: https://cassette.gg/agents/find-a-game.md

This is a vendor-hosted service; the server implementation is not public source.
