# RepeatPost MCP

Manage social media with AI using RepeatPost.

RepeatPost MCP lets authorized users create and schedule social media posts, generate captions, manage drafts, organize media, and work with connected social channels.

## Documentation

Visit the [RepeatPost MCP documentation](https://www.repeatpost.com/mcp).

## Remote endpoint

https://api.repeatpost.com/mcp

## Authentication

RepeatPost supports OAuth authorization. Users must authorize access to their RepeatPost account before using protected tools.
