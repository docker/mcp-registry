## Quick Start

The You.com MCP server provides AI-powered web search, content extraction, and research capabilities through the Model Context Protocol.

### Features
- **Real-time web search** - Current information from across the web
- **Content extraction** - Full content from URLs with smart parsing  
- **Cited research** - Multi-source research with automatic citations
- **Keyless mode** - Works without API key (daily limits apply)
- **Enhanced mode** - Full features with YDC_API_KEY

### Authentication
- **Keyless**: Basic search functionality (100 requests/day per IP)
- **API Key**: Enhanced features and higher limits ([Get API key](https://you.com/platform/api-keys?utm_source=docker-mcp-registry&utm_medium=integration&utm_campaign=api-keys))

### Available Tools
- `you-search` - Web search with real-time results
- `you-contents` - Extract content from URLs  
- `you-research` - Multi-source research with citations
