# AI Applyd

Find jobs matched to your resume, prepare each application and submit it on the employer's own hiring site. AI Applyd supports 34 hiring systems, including Workday, Greenhouse, Lever, Ashby and iCIMS.

## What you can do

Find and filter matched roles, read the posting, save or skip a match, and set your target roles, locations and salary. Score your resume against a job description, identify missing keywords, tailor the resume and write a cover letter from your own experience.

Send an application automatically or hold it for your review. Inspect the documents, request changes and approve the applications you want to send. Track status and the employer receipt or confirmation page. Prepare for interviews with role-specific questions, answer guidance and STAR examples.

Translate a saved resume-builder document or create a private editable resume draft to finish and export in the builder. Check account readiness, saved resumes and the remaining application allowance from the conversation.

## Connect

Connect your AI Applyd account through the browser sign-in. The server uses Streamable HTTP at `https://mcp.aiapplyd.com/mcp` with OAuth 2.1, dynamic client registration and PKCE. It does not require a personal access token pasted into chat.

The server exposes 17 tools, four prompts and three resources. Discovery is available before sign-in; tool calls require a connected account. Account reads do not generate AI content. Generation uses account AI tokens and action limits. Application submission uses application allowance.

Applying sends information to an employer. Use review mode to hold an application until you approve it. A submit click is not proof that an application landed; check the employer confirmation returned by the tool.
