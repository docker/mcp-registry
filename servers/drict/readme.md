# Drict MCP Server

**Drict** checks the printed text of a product label against the label law of the country where it is sold, for 48 countries. It lists what is found (with the line it was found on), what is missing, what applies only in some cases and what to check by eye. Each point names its law and links to the official source.

Tools: `list_markets`, `list_requirements`, `check_label`. All three are read-only and need no sign-in or API key.

It is not legal advice, and it never says a label is "compliant".

Docs: https://github.com/drint-io/drict-mcp · Website: https://drint.io/drict
