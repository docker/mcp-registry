# Orbit

[MCP setup and tool documentation](https://github.com/Noveum/orbit/blob/main/docs/mcp.md)

Connect to the hosted Streamable HTTP endpoint at https://orbit.noveum.ai/mcp. Sign in to Orbit, select a workspace and approve read or write scopes. Complete any requested passkey verification. Existing user permissions apply to every tool call.

Orbit is free and Apache-2.0. The source repository contains the complete application and its integrated MCP implementation. Self-hosting is Preview; standalone Node evaluation lacks realtime.
