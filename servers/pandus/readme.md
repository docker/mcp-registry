Docs: https://pandus.online/en/accessibility-mcp-server

Source of the MCP server package and tool list: https://github.com/Pandus-Online/mcp

Without signing in, the server explains any axe-core rule or WCAG 2.2 success criterion with fixes
for code, Shopify, WooCommerce, PrestaShop and Shoptet. After OAuth sign-in (Pro and Agency plans)
it lists your sites, says what to fix first, starts a new check and compares two checks.
Results are an automated check, not a full audit and not legal advice.
