# Brainy Prices

UAE cost of living data: school fees (KHDA), registered rents (DLD), fuel, utilities, telecom plans and relocation costs, with source and date on every answer.

[Documentation](https://prices.brainy.ae/developers.html)

Remote Streamable HTTP: `https://prices.brainy.ae/mcp/v2`. Read-only; no authentication.
