# MMW Managed Memory Workspace

MMW is a shared memory for AI agents: Claude Code, Cursor, Codex and ChatGPT read and write the same workspace over MCP. Facts keep their source and date, newer versions supersede old ones, and contradicting facts are flagged.

Tools: remember, search, search_history, validate_memory, forget.

- **Website**: [https://mmwhub.tech](https://mmwhub.tech)
- **Documentation & Source**: [https://github.com/msingatullin/mmw-mcp](https://github.com/msingatullin/mmw-mcp)
