# Remote Impact Jobs MCP Server

Structured data on open remote roles at impact organizations: climate, global health, AI safety, animal welfare, effective altruism and more. Agents can search by the applicant's country, impact area, job type, level, minimum pay and recency, fetch a full role record with its source link and eligibility details, list impact areas, and look up an organization's open roles.

Docs: https://remoteimpact.org/developers/
